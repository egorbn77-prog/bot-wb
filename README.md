# 🤖 Бот для ответов на отзывы Wildberries

Автоматический бот для ответов на отзывы в личном кабинете Wildberries с веб-интерфейсом управления.

## 📋 Возможности

- **Автоматические ответы** на отзывы по заранее настроенным сценариям
- **База знаний** с информацией о компании, товарах и условиях
- **Интеграция с AI** (OpenAI, Anthropic, Google Gemini, YandexGPT, DeepSeek, OpenRouter)
- **Веб-интерфейс** для управления сценариями и базой знаний
- **Mock-режим** для тестирования без подключения к API Wildberries

## 🚀 Быстрый старт

### Требования

- Bun >= 1.0.0
- Node.js >= 20.0.0

### Установка

```bash
# Клонирование репозитория
git clone <repository-url>
cd wb-review-bot

# Установка зависимостей
bun install

# Запуск в режиме разработки
bun dev
```

Приложение будет доступно по адресу: http://localhost:3000

### Сборка для продакшена

```bash
bun build
bun start
```

### Настройка

#### 1. API Wildberries

1. Получите API ключ в личном кабинете Wildberries
2. Перейдите в **Настройки → API Wildberries**
3. Введите API ключ
4. Нажмите "Сохранить"

#### 2. AI провайдер

Бот поддерживает несколько AI провайдеров:

| Провайдер | Описание |
|-----------|----------|
| OpenAI | GPT-4, GPT-3.5 |
| Anthropic | Claude 3 |
| Google Gemini | Gemini Pro |
| YandexGPT | Яндекс GPT |
| DeepSeek | DeepSeek Chat |
| OpenRouter | Доступ к множеству моделей |
| Custom | Любой OpenAI-совместимый API |

Для настройки:
1. Перейдите в **Настройки → AI провайдер**
2. Выберите провайдера
3. Введите API ключ
4. Выберите модель
5. Нажмите "Сохранить"

#### 3. Сценарии ответов

Сценарии определяют, какие ответы будут отправляться на отзывы.

**Структура сценария:**
- **Название** - для идентификации
- **Приоритет** - порядок проверки (1-100, ниже = раньше)
- **Условия**:
  - Ключевые слова - триггеры срабатывания
  - Режим поиска - любое слово / все слова / точное совпадение
  - Исключающие слова - блокируют срабатывание
- **Шаблон ответа** - текст ответа с переменными

**Переменные в шаблонах:**
- `{productName}` - название товара
- `{authorName}` - имя автора отзыва
- `{date}` - дата отзыва

**Пример сценария:**

```json
{
  "name": "Благодарность за положительный отзыв",
  "priority": 10,
  "conditions": {
    "keywords": ["отлично", "супер", "класс", "рекомендую"],
    "keywordMode": "any"
  },
  "template": {
    "text": "Здравствуйте, {authorName}! Спасибо за высокую оценку! Рады, что вам понравилось. Ждем вас снова!"
  }
}
```

**Структура записи:**

- Приоритет

### Режимы работы бота

#### Автоматический режим

Бот автоматически:
1. Получает новые отзывы из API Wildberries
2. Подбирает подходящий сценарий
3. Генерирует ответ (с AI или по шаблону)
4. Отправляет ответ

#### Режим подтверждения

Бот:
1. Получает новые отзывы
2. Генерирует варианты ответов
3. Ожидает подтверждения оператора
4. Отправляет после подтверждения

### Тестирование без API Wildberries

Приложение работает в mock-режиме по умолчанию. Для тестирования:

1. Не вводите API ключ Wildberries
2. Бот будет использовать тестовые данные
3. Все функции доступны для проверки

### Безопасность

- API ключи хранятся в JSON файлах (для продакшена рекомендуется использовать переменные окружения)
- Доступ только из локальной сети
- Нет авторизации (предполагается локальное использование)

### Переменные окружения

Создайте файл `.env.local` для продакшена:

```env
# API Wildberries
WB_API_KEY=your_wb_api_key

# AI провайдер
AI_PROVIDER=openai
AI_API_KEY=your_ai_api_key
AI_MODEL=gpt-4

# Настройки бота
BOT_AUTO_START=false
BOT_INTERVAL_MINUTES=30
```

### Добавление нового AI провайдера

1. Добавьте тип провайдера в `src/types/settings.ts`
2. Реализуйте генератор в `src/lib/ai/generator.ts`
3. Добавьте UI настройки в `src/app/settings/page.tsx`

### Добавление новой категории базы знаний

1. Добавьте категорию в `src/data/knowledge-base.json`
2. Категория автоматически появится в интерфейсе

## 🚀 Деплой на бесплатных платформах

Подробная инструкция по развертыванию доступна в файле [DEPLOYMENT.md](./DEPLOYMENT.md).

### Быстрый деплой на Vercel (рекомендуется)

1. Загрузите код на GitHub
2. Зайдите на [vercel.com](https://vercel.com) и авторизуйтесь через GitHub
3. Нажмите "Add New..." → "Project" и выберите репозиторий
4. Добавьте переменные окружения:
   - `DB_URL` - URL базы данных Turso/LibSQL
   - `DB_TOKEN` - токен авторизации базы данных
5. Нажмите "Deploy"

### Бесплатная база данных

Для продакшена рекомендуется использовать [Turso](https://turso.tech):
1. Зарегистрируйтесь бесплатно на turso.tech
2. Создайте базу данных
3. Получите `DB_URL` и `DB_TOKEN`
