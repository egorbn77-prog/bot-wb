# План реализации бота для Wildberries

## 📋 Этапы разработки

### Этап 1: Базовая инфраструктура
**Цель:** Создать основу проекта с необходимыми зависимостями

#### Задачи:
- [ ] **1.1** Установить дополнительные зависимости
  - `drizzle-orm` — ORM для работы с БД
  - `better-sqlite3` — драйвер SQLite
  - `zod` — валидация данных (уже есть в проекте)
  
- [ ] **1.2** Настроить структуру директорий
  - Создать `src/lib/` для библиотек
  - Создать `src/components/` для компонентов
  - Создать `src/types/` для типов
  - Создать `src/data/` для JSON файлов

- [ ] **1.3** Настроить базу данных
  - Создать схему Drizzle
  - Настроить миграции
  - Создать начальные данные

---

### Этап 2: API Wildberries (Блок 1)
**Цель:** Реализовать клиент для работы с API Wildberries

#### Задачи:
- [ ] **2.1** Создать типы данных API
  - `src/types/api.ts` — типы запросов/ответов
  - `src/types/review.ts` — тип отзыва

- [ ] **2.2** Реализовать клиент API
  - `src/lib/wb-api/client.ts` — базовый клиент
  - `src/lib/wb-api/endpoints.ts` — константы эндпоинтов
  - `src/lib/wb-api/types.ts` — внутренние типы

- [ ] **2.3** Реализовать методы API
  - `getReviews()` — получение отзывов
  - `sendAnswer()` — отправка ответа
  - Обработка ошибок

---

### Этап 3: Система сценариев (Блок 3)
**Цель:** Реализовать движок обработки отзывов по сценариям

#### Задачи:
- [ ] **3.1** Создать типы сценариев
  - `src/types/scenario.ts` — тип сценария

- [ ] **3.2** Реализовать сопоставление шаблонов
  - `src/lib/scenarios/matcher.ts` — поиск подходящего сценария
  - Поддержка ключевых слов
  - Приоритизация сценариев

- [ ] **3.3** Реализовать шаблоны ответов
  - `src/lib/scenarios/templates.ts` — работа с шаблонами
  - `src/lib/scenarios/variables.ts` — подстановка переменных
  - Переменные: `{productName}`, `{authorName}`, `{date}` и т.д.

- [ ] **3.4** Создать начальные сценарии
  - `src/data/scenarios.json` — примеры сценариев

### Этап 6: API Routes
**Цель:** Создать backend API для веб-интерфейса

#### Задачи:
- [ ] **6.1** API отзывов
  - `GET /api/reviews` — список отзывов
  - `GET /api/reviews/[id]` — детали отзыва
  - `PATCH /api/reviews/[id]` — обновление статуса

- [ ] **6.2** API сценариев
  - `GET /api/scenarios` — список сценариев
  - `POST /api/scenarios` — создание
  - `PUT /api/scenarios/[id]` — обновление
  - `DELETE /api/scenarios/[id]` — удаление

- [ ] **6.3** API базы знаний
  - `GET /api/knowledge-base` — список записей
  - `POST /api/knowledge-base` — создание
  - `PUT /api/knowledge-base/[id]` — обновление
  - `DELETE /api/knowledge-base/[id]` — удаление

- [ ] **6.4** API настроек
  - `GET /api/settings` — получение настроек
  - `PUT /api/settings` — сохранение настроек

- [ ] **6.5** API бота
  - `POST /api/bot/start` — запуск
  - `POST /api/bot/stop` — остановка
  - `GET /api/bot/status` — статус

## 🚀 Порядок реализации

Рекомендуемый порядок для быстрого запуска MVP:

1. **Этап 1** → Базовая инфраструктура
2. **Этап 2** → API Wildberries (только получение отзывов)
3. **Этап 3** → Сценарии (базовая реализация)
4. **Этап 5** → Ядро бота (без планировщика)
5. **Этап 6** → API Routes (базовые)
6. **Этап 7** → Веб-интерфейс (дашборд + отзывы)
7. **Этап 4** → База знаний
8. **Этап 2** → API Wildberries (отправка ответов)
9. **Этап 5** → Ядро бота (планировщик)
10. **Этап 7** → Веб-интерфейс (остальные страницы)
11. **Этап 8** → Документация

## ⚠️ Зависимости от ответов пользователя

План может быть скорректирован на основе ответов:

| Вопрос | Вариант A | Вариант B | Вариант C |
|--------|-----------|-----------|-----------|
| База знаний | JSON файлы (проще) | SQLite + Drizzle | Внешнее API |
| Логика ответов | Только шаблоны | Только AI | Шаблоны + AI |
| Авторизация | Нет | Простой пароль | Система пользователей |
